# ✊ Камък Ножица Хартия ✌️

Класическата игра Камък-Ножица-Хартия, но с по-хубав дизайн и малко анимации.

Направих я просто за забавление и да си поиграя с JavaScript.

## Какво има вътре

- Приятен и цветен дизайн
- Анимации, когато избираш и когато печелиш
- Конфети, когато победиш (много ми харесва тази част 😄)
- Следи твоя най-добър резултат
- Работи добре и на телефон

## Как се играе

Избираш между Камък, Хартия или Ножица и гледаш дали ще биеш компютъра. Нищо сложно, чиста класика.

Правила са стандартните:
- Камък бие Ножица
- Ножица бие Хартия  
- Хартия бие Камък

## Технологии

- HTML
- CSS
- JavaScript (без никакви библиотеки)
